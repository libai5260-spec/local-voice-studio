# Voice Studio · 本地女声工作室

这是一个为 Apple 芯片 Mac 制作的本地女声工作室，默认使用 Fish S2 Pro 的 MLX 本地版（44.1 kHz），保留 Chatterbox 浏览器模型作为备用。不是 Fish Audio 官网或云端接口；效果不保证与其最新托管模型完全相同。

> **这是可下载、在自己电脑上运行的软件，不是打开 GitHub 链接就能立即生成的在线网站。** 首次使用需要联网下载运行组件和模型；准备完成后在本机生成。仓库不包含模型权重、运行环境、私人录音或生成历史。

## 运行要求

- Apple Silicon Mac（M 系列芯片）；当前一键流程不支持 Intel Mac、Windows 或 Linux。
- **推荐 24 GB 或更多统一内存**。Fish BF16 占用较高，不保证较低内存机器可稳定运行；使用时关闭其他大型模型和多余生成标签页。
- **建议预留至少 30 GB 可用磁盘空间**，供模型、Python / Node 运行组件、依赖和下载缓存使用。其中 Fish 模型本身约 11 GB，Chatterbox 备用模型另需约 2 GB；实际占用随依赖版本变化。
- 推荐 Google Chrome；Chatterbox 使用 WebGPU，具体支持情况由浏览器和设备决定。
- Fish 引擎需要 Python 3.12 或 3.13（推荐 3.12）；如果没有，请先从 [Python 官方网站](https://www.python.org/downloads/macos/)安装。准备脚本只创建项目隔离环境，不自动安装系统 Python。Chatterbox 不需要 Python。
- 首次需要访问 GitHub、npm、Python 软件包源和 Hugging Face。大模型下载可能耗时较长，没有固定完成时间；Fish 下载支持断点续传和最终校验。

## 首次准备

1. 阅读下面的[许可与使用范围](#许可与使用范围)，尤其是 Fish 的非商业限制。
2. 下载 ZIP 并解压到自己准备长期保留的文件夹，不要直接在压缩包内运行。
3. 双击 **“首次安装.command”**，选择准备方式：`1` Fish 高品质（默认，需 Python）、`2` Chatterbox 备用（不需 Python）或 `3` 仅网站组件（不下载模型、暂时不能生成）。脚本会自动下载项目专用 Node.js 并安装网站依赖；Fish 会要求先阅读许可、输入 `YES` 后才开始下载约 11 GB 模型。
4. 首次准备成功后双击 **“启动声音工作室.command”**，在网页中选择刚才准备的引擎。日常启动不会自动下载缺失模型；需要补装或续传时，再运行“首次安装.command”即可。
5. 等界面显示所选模型已就绪，再点击“先试读一段”。**下载完成、模型载入完成与实际语音生成成功是不同阶段**；首次载入也可能需要等待。

macOS 若询问是否允许打开脚本，请先检查来源和文件内容，再通过系统提供的“打开”确认。若脚本提示缺少执行权限，可在项目目录中运行 `zsh 首次安装.command` 或 `zsh 启动声音工作室.command`。不需要关闭系统安全保护。

## 日常使用

1. 双击 **“启动声音工作室.command”**。
2. 启动器会打开 Chrome 中的 `http://localhost:3000`，并启动已安装的 Fish 本地服务。使用期间保持启动窗口运行。请始终使用相同地址与 Chrome 个人资料，避免因浏览器来源不同而看不到音色记录。
3. 从 10 个美国女声中选择一个。也可上传或录制授权女声，并填写参考录音实际说出的英文原文（不是待生成的新文案）。
4. 输入英文，选择表达方向，点击“先试读一段”。满意后再“生成完整语音”。试读和全文都会保留在历史中。
5. 点击短停顿或长停顿，会在光标处插入标签。生成稳定性控制随机变化；不会进行后期变速变调。
6. 在历史中点击“复用参数”，可继续修改同一份完整文案。草稿与设置自动保存在本机。

试听一次只能播放一条，必须等当前试听结束后才能试听另一条。历史最多保留最近 24 条，重要成品请及时下载备份。

## 功能

- 麦克风录音和音频上传
- 默认只展示 10 个经元数据验证的美国女性 VCTK 参考音色；原有音色数据保留，不删除
- 多音色命名、保存、试听和删除
- 长文按句子和语义停顿分段，合并过短句子，保留段落间停顿
- 长文生成显示真实段落进度与已用时间；超长片段未读完时自动拆分重试
- 连续生成后释放显存缓存；播放和导出保留原声，减少重复静音造成的断续感
- Fish 原生表达指令和语气标签；Chatterbox 备用只暴露实际支持的语气强弱与采样设置
- 生成前录音音量、时长和破音检查（并非自动降噪或语音识别）
- 真正生成开头一小段的试读功能，方便比较不同音色和设置
- 短停顿 `[pause]` 为 0.35 秒，长停顿 `[long pause]` 为 0.75 秒，不朗读标签文字
- 舒缓、自然、明快三档自然节奏：调整停顿，不拉伸人声波形
- 真人质感保护：保留模型原生音色与音调，不做产生金属感的后期变速变调
- 本地生成历史
- WAV 和 MP3 下载
- Fish 原生 44.1 kHz / Chatterbox 24 kHz 全链路保真保存、播放和导出

表达、相似度和语速是生成模型的结果，不能保证精确数值或每次一致。建议先试读，再生成长文。Fish 参考录音须为 2–30 秒，推荐干净、无背景音乐的录音，并填写完整、准确的原文。

## Fish 本地安装与检查

熟悉终端的使用者可在项目目录中依次运行以下手动流程；首次准备完成后，无需每次重复下载：

```sh
./scripts/fish-install.sh
./scripts/fish-download.sh
./scripts/fish-start.sh
```

隔离环境、模型与缓存位于 `.runtime/fish/`，不修改系统 Python。BF16 模型约 11 GB，运行需较多统一内存；不要同时运行多个模型或打开多个生成标签页。下载脚本固定模型版本并支持断点续传。安装和下载需要联网，推理服务强制离线读取已下载权重。

中断下载后重新运行 `./scripts/fish-download.sh`，会续传未完成文件；不要删除已经下载的数据。手动安装同样需要 Python 3.12 或 3.13；具体检查结果以安装脚本提示为准。

本地健康接口：`http://127.0.0.1:7861/health`。网页会显示模型准备情况，未就绪时禁用 Fish 生成按钮。原 Chatterbox 可在“本地生成引擎”中选择。关闭一键启动窗口会停止该窗口启动的服务。

## 隐私和授权

音色、生成历史和草稿保留在当前浏览器中。Fish 推理时，选择的参考录音、原文及待生成文案只发送给本机 `127.0.0.1:7861`，不发送到 Fish Audio、Hugging Face 或其他云端。服务仅监听 loopback，并检查网页来源；不要将端口公开到互联网。参考录音在推理服务内存中处理，不额外落盘。

分享本仓库不会分享你的音色、草稿或历史。请不要把 `.runtime/`、`public/models/`、`.env*`、个人导出录音或浏览器数据另行提交到 GitHub。切换浏览器、个人资料或地址会看到不同存储；清除网站数据会丢失记录。

模型文件首次从 Hugging Face 下载到本地；下载模型与上传个人录音是不同操作。内置 VCTK 音色的原文来自数据集元数据，旧的自建音色缺少原文时可在备用模型中使用，或重新上传并填写原文后用于 Fish。

仅克隆你本人或已经明确获得授权的声音。不得用于冒充他人、欺诈或未经同意的误导性内容；内置数据集署名不代表录音者为本项目背书。

## 常见问题

**朋友打开 GitHub 后为什么不能直接输入文字生成？**

GitHub 在这里托管的是源码。朋友需要下载并在符合要求的 Mac 上准备模型。本地地址 `localhost` 只指向每个人自己的电脑，不是远程共享网址。GitHub Pages 不能直接替代这个需要本地 Python / MLX 的 Fish 服务；本仓库没有部署公共生成服务。

**Fish 显示未准备、离线或正在载入？**

确认首次安装、模型下载已经完成，并使用启动器保持服务运行。下载百分比不是载入百分比。模型校验完成后服务会自动载入，未就绪时网页不会允许 Fish 生成；也可在“本地生成引擎”中选择已准备好的 Chatterbox 备用模型。

**保存的音色不见了？**

先检查是否仍使用原来的 Chrome 个人资料和 `http://localhost:3000`。不要急着清除网站数据；它会删除本机保存的音色与历史。

**能让全网或多人直接访问这台电脑的服务吗？**

当前服务只监听本机回环地址，并校验网页来源；没有面向公网的账号、配额或多人任务系统。不要直接转发或公开端口。源码公开不等于已建立安全的公共服务。

## 开发与验证

源代码主要位于 `app/`（界面、音频处理与浏览器模型）、`backend/`（Fish 本地服务）和 `scripts/`（安装 / 下载 / 启动）。模型、依赖、缓存和构建产物均在 `.gitignore` 中排除。

使用 Node.js 22.13 或更高版本，在项目目录中运行：

```sh
npm ci
npm run dev
```

网页地址为 `http://localhost:3000`。开发服务器本身不会替代模型下载；Chatterbox 模型准备使用 `./scripts/download-voice-model.sh`，Fish 使用上面的独立流程。

```sh
npm test
npx tsc --noEmit
.runtime/fish/venv/bin/python -m unittest discover -s backend -p 'test_*.py' -v
```

`npm test` 先构建再运行前端 / 音频逻辑测试；Python 测试需要先安装 Fish 环境。自动化逻辑测试不能代替下载完成后的真实合成和人工试听。
